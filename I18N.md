# Internacionalización (i18n) y localización (l10n)

LegalAI se puede usar en **español** e **inglés**. El selector **ES / EN** está en la barra superior. Al pulsarlo suena un tono corto y el cambio se aplica al instante, sin recargar la página. El idioma elegido se guarda en el navegador.

- **i18n:** los textos de la interfaz se traducen.
- **l10n:** fechas, números y tamaños usan el formato de cada idioma:
  - `es` → `es-PE` (`18/11/2026 10:30`, `1,5 MB`);
  - `en` → `en-US` (`11/18/2026, 10:30 AM`, `1.5 MB`).

Módulos traducidos: **Documentos**, **Fragmentos**, **Auditoría** y **Reportes**.

## Piezas

| Archivo | Qué hace |
|---|---|
| `src/app/i18n/es.ts` | Diccionario base en español |
| `src/app/i18n/en.ts` | Diccionario en inglés. TypeScript exige que tenga **todas** las claves de `es.ts` |
| `src/app/services/i18n.service.ts` | Idioma como `signal`, `t(clave, params)`, `formatDate`, `formatNumber` y `formatBytes` |
| `src/app/shared/i18n/i18n.pipes.ts` | Pipes `t`, `ldate` y `lnumber` para las plantillas |
| `src/app/shared/i18n/language-switcher.ts` | Selector ES/EN accesible, con sonido |
| `src/app/services/ui-sound.service.ts` | Sonido corto con Web Audio, sin archivos de audio |

## Cómo traducir tu módulo

1. **Agrega tus claves** con un prefijo propio en `es.ts` y la misma clave en `en.ts`:
   ```ts
   // es.ts
   'clients.title': 'Clientes',
   'clients.deleted': 'Cliente {name} eliminado.',
   // en.ts
   'clients.title': 'Clients',
   'clients.deleted': 'Client {name} deleted.',
   ```
2. **Importa los pipes** en tu componente:
   ```ts
   import { I18N_PIPES } from '../../shared/i18n/i18n.pipes';
   imports: [FormsModule, ...I18N_PIPES],
   ```
3. **En la plantilla:**
   ```html
   <h1>{{ 'clients.title' | t }}</h1>
   <p>{{ 'clients.deleted' | t: { name: client.fullNameOrCompany } }}</p>
   <td>{{ client.createdAt | ldate }}</td>
   <strong>{{ total | lnumber }}</strong>
   <input [placeholder]="'clients.search' | t" />
   ```
4. **En TypeScript** (avisos y validaciones):
   ```ts
   readonly i18n = inject(I18nService);
   this.notice = this.i18n.t('clients.deleted', { name });
   ```

## Reglas

- **No escribas textos fijos** en las plantillas: usa siempre una clave.
- **Mismos parámetros en ambos idiomas.** Cada `{parametro}` de una clave debe existir en `es.ts` y en `en.ts`. Las pruebas de `i18n.service.spec.ts` lo verifican, igual que el conjunto de claves.
- **Mensajes del servidor:** se muestran tal como llegan del backend.
- **Pruebas:** el idioma por defecto es español, así que tus pruebas actuales siguen funcionando.
